# SamWin - Real Estate & Property Solutions

SamWin is a comprehensive real estate property listing & marketing platform designed for web and mobile.

## Features
- **Modern Responsive Web Portal**: High performance, SEO-optimized property listing engine.
- **Super Admin Dashboard**: Full control over listings, users, approvals, and white-label settings.
- **Flutter Mobile Application**: Native Android & iOS app experience with Riverpod state management.
- **RESTful API Backend**: PHP/MySQL backend with support for local SQLite/JSON offline fallback.

## Directory Structure
- `api/`: Backend PHP REST API & Database migrations
- `admin/`: Super Admin Web Dashboard
- `lib/`: Flutter Mobile App codebase
- `assets/images/`: Logos and branding assets
- `.env`: Environment and White-label configuration
